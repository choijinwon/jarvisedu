# jarvisedu

고등 진학상담 앱 MVP 템플릿 (React + TypeScript + Vite).

## 포함 파일
- `src/types.ts`
- `src/mocks/*`
- `src/services/mockApi.ts`
- `src/hooks/*`
- `src/screens/*`
- `src/utils/pdf.ts`
- `src/App.tsx`

## 실행
```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 열면 탭 기반 데모를 확인할 수 있습니다.
